# Vocabulary Learning App — ABOUT

## 1. О приложении

Это нативное приложение для iPhone, iPad и Mac, предназначенное для долгосрочного изучения и запоминания иностранных слов.

Главная идея приложения — не быть обычным словарём, а стать персональной системой запоминания слов. Пользователь постепенно расширяет словарный запас, а приложение само определяет, какие слова показать сегодня, какие нужно повторить и какие уже хорошо запомнены.

Основной цикл обучения:

**NEW WORD → LEARN → REVIEW → REMEMBER → MASTER**

Приложение должно быть простым в использовании, быстрым, минималистичным и максимально нативным для экосистемы Apple.

---

## 2. Главная цель

Создать приложение, которое помогает пользователю регулярно и без перегрузки увеличивать словарный запас иностранного языка.

Приложение должно:

- каждый день предлагать новые полезные слова;
- автоматически планировать повторения;
- учитывать индивидуальный прогресс пользователя;
- помогать понять значение, произношение и использование слова;
- позволять добавлять собственные слова;
- работать без интернета для основной части обучения;
- постепенно синхронизировать данные между устройствами;
- превращать изучение слов в простую ежедневную привычку.

Главный принцип:

> Пользователь не должен думать о том, какие слова и когда ему повторять. Этим занимается приложение.

## 3. Целевая аудитория

Основная аудитория:

- люди, изучающие английский и другие иностранные языки;
- школьники и студенты;
- пользователи, готовящиеся к IELTS и другим языковым экзаменам;
- люди, которые хотят расширить словарный запас;
- пользователи, которым недостаточно обычного словаря;
- пользователи, которым нужны SRS/flashcards, но хочется более современного и нативного интерфейса.

Приложение должно быть понятно как начинающему пользователю, так и человеку, который уже знаком с интервальным повторением.

---

## 4. Основная концепция

Приложение объединяет четыре основных компонента:

1. **Dictionary**
   - перевод;
   - определения;
   - часть речи;
   - произношение;
   - IPA;
   - примеры;
   - синонимы;
   - антонимы;
   - аудио.

2. **Daily Words**
   - новые слова каждый день;
   - подбор слов на основе уровня и прогресса;
   - отсутствие повторной выдачи уже освоенных слов;
   - контроль дневного количества новых слов.

3. **Spaced Repetition**
   - автоматическое планирование повторений;
   - индивидуальные интервалы;
   - оценка сложности слова;
   - отслеживание правильных и неправильных ответов;
   - определение момента, когда слово можно считать хорошо запомненным.

4. **Personal Vocabulary**
   - пользовательские слова;
   - собственные примеры;
   - пользовательские заметки;
   - поиск;
   - статусы изучения;
   - история повторений.

## 5. Daily Word

Каждый день пользователь получает новое слово.

Приложение должно выбирать слово с учётом:

- уровня пользователя;
- предыдущих изученных слов;
- истории повторений;
- сложности;
- частотности;
- интересов пользователя в будущем;
- уже известных и исключённых слов.

Слово не должно снова становиться Daily Word, если пользователь уже достаточно хорошо его освоил или явно отметил как известное.

Для каждого Daily Word необходимо сохранять дату назначения.

Например:

```text
2026-10-08
Word: accomplish
Status: learning
```

Это позволяет гарантировать стабильность Daily Word в течение дня.

---

## 6. Система запоминания

Приложение использует интервальное повторение.

Для каждого слова необходимо хранить состояние памяти.

Пример состояний:

```text
new
learning
reviewing
remembered
known
suspended
```

Также необходимо хранить:

```text
repetitionCount
correctCount
incorrectCount
lastReviewedAt
nextReviewAt
interval
difficulty
stability
status
```

Алгоритм повторений должен быть изолирован от остального приложения, чтобы его можно было заменить или улучшить без переписывания интерфейса и модели данных.

В качестве концепции можно использовать подход, похожий на Anki/FSRS, но реализация должна быть собственной и заменяемой.

---

## 7. Review

Во время повторения пользователь видит карточку слова.

На лицевой стороне:

```text
accomplish
```

После нажатия пользователь получает:

```text
translation
definition
pronunciation
example
```

Пользователь оценивает, насколько хорошо он вспомнил слово:

```text
Again
Hard
Good
Easy
```

После этого приложение рассчитывает следующий интервал.

Цель — минимизировать ручное управление расписанием.

## 10. Примеры предложений

## 11. API и внешние источники

Приложение должно использовать абстракции, а не напрямую связывать UI с конкретными API.

Предусмотреть протоколы:

```text
DictionaryService
TranslationService
ExampleSentenceService
PronunciationService
```

Возможная стратегия получения данных:

```text
Local Data
    ↓
Cache
    ↓
Apple Frameworks
    ↓
Free Dictionary API
    ↓
Tatoeba
    ↓
Optional Providers
```

Внешние сервисы используются как дополнительный источник информации, а не как обязательная часть приложения.

Основное обучение должно продолжать работать без интернета.

API-ответы необходимо кэшировать локально.

API keys и секреты никогда не должны находиться непосредственно в клиентском приложении.

## 12. Offline-first

Приложение должно быть прежде всего локальным.

Без интернета пользователь должен иметь возможность:

- просматривать слова;
- изучать новые слова;
- повторять карточки;
- видеть свой прогресс;
- искать слова;
- добавлять собственные слова;
- редактировать примеры и заметки;
- получать Daily Word из локального словаря.

Интернет необходим только для дополнительного обогащения данных и будущей синхронизации.

Принцип:

> Network is an enhancement, not a requirement.

---

## 13. Встроенный словарь

Приложение должно иметь собственный локальный набор слов.

На старте желательно использовать примерно:

```text
1000–3000 words
```

Основной словарь должен быть ориентирован на:

- A2;
- B1;
- B2;
- IELTS;
- частотную лексику;
- phrasal verbs;
- collocations;
- полезные академические слова.

Данные должны храниться отдельно от Swift-кода, например в JSON.

Пример:

```json
{
  "word": "accomplish",
  "translation": "достигать, выполнять",
  "partOfSpeech": "verb",
  "level": "B1",
  "definition": "to successfully complete something",
  "examples": [
    "She accomplished her goal."
  ]
}
```

Для встроенных данных необходимо хранить информацию об источнике и лицензии.

Нельзя без соответствующей лицензии распространять защищённые базы данных Oxford, Cambridge, Google и других коммерческих словарей.

## 16. Streak

Приложение может использовать простую систему серий.

День считается выполненным, если пользователь завершил хотя бы одну полноценную учебную активность.

Например:

```text
MON  TUE  WED  THU  FRI
 ✓    ✓    ✓    ✓    ✓
```

Главная цель streak — поддерживать регулярность, а не заставлять пользователя заниматься часами.

- интерфейс с десятками экранов;
- приложение, которое постоянно требует интернет;
- приложение, полностью зависящее от одного API.

Главная функция приложения — **помочь пользователю запомнить слово и вовремя его повторить**.

---

## 33. Product Philosophy

Приложение должно ощущаться как:

> **A personal memory system for language.**

Не просто:

> "Вот перевод слова."

А:

> "Я знаю, что ты изучаешь это слово. Я помню, когда ты его видел, насколько хорошо ты его помнишь и когда тебе стоит увидеть его снова."

Система должна постепенно становиться персональной моделью словарного запаса пользователя.

---

## 34. Итог

Приложение представляет собой нативную Apple-платформу для долгосрочного изучения иностранной лексики.

Основная формула продукта:

```text
DICTIONARY
+
DAILY WORD
+
SPACED REPETITION
+
PERSONAL VOCABULARY
+
OFFLINE-FIRST
+
NATIVE APPLE UX
=
PERSONAL VOCABULARY MEMORY SYSTEM
```

Главная задача первой версии — сделать ежедневное изучение слов настолько простым, чтобы пользователь мог открыть приложение, потратить несколько минут и закрыть его с ощущением, что он действительно что-то запомнил.
