# Vocabulary Learning App — ABOUT

## 1. О приложении

Это нативное приложение для iPhone, iPad и Mac, предназначенное для долгосрочного изучения и запоминания иностранных слов.

Главная идея приложения — не быть обычным словарём, а стать персональной системой запоминания слов. Пользователь постепенно расширяет словарный запас, а приложение само определяет, какие слова показать сегодня, какие нужно повторить и какие уже хорошо запомнены.

Основной цикл обучения:

**NEW WORD → LEARN → REVIEW → REMEMBER → MASTER**

Соответствие этапов цикла статусам слова (см. раздел 6):

```text
NEW WORD → new
LEARN    → learning
REVIEW   → reviewing
REMEMBER → remembered   (автоматически, по интервалу)
MASTER   → known        (вручную, «Я это знаю»)
```

### Языки в MVP

В первой версии поддерживается одна пара языков: **английский → русский**. Интерфейс: английский и русский.

Модель данных сразу хранит изучаемый язык и язык перевода, чтобы позже добавить другие пары без миграции. Дополнительные языки в MVP не реализуются.

Приложение должно быть простым в использовании, быстрым, минималистичным и максимально нативным для экосистемы Apple.

## 2. Главная цель

Создать приложение, которое помогает пользователю регулярно и без перегрузки увеличивать словарный запас иностранного языка.

Приложение должно:

- каждый день предлагать новые полезные слова;
- автоматически планировать повторения;
- учитывать индивидуальный прогресс пользователя;
- помогать понять значение, произношение и использование слова;
- позволять добавлять собственные слова;
- работать без интернета для основной части обучения;
- постепенно синхронизировать данные между устройствами;
- превращать изучение слов в простую ежедневную привычку.

Главный принцип:

> Пользователь не должен думать о том, какие слова и когда ему повторять. Этим занимается приложение.

## 4. Основная концепция

Приложение объединяет четыре основных компонента:

1. **Dictionary**
   - перевод;
   - определения;
   - часть речи;
   - произношение;

4. **Personal Vocabulary**

   - пользовательские заметки;
   - поиск;
   - статусы изучения;

## 5. Daily Word

Каждый день пользователь получает одно главное слово — **Daily Word**. Оно показывается на экране Today.

Остальные новые слова, до дневного лимита из Settings («количество новых слов в день»), попадают в очередь Learn. Daily Word всегда входит в этот лимит и считается первым из новых слов дня.

Приложение должно выбирать слово с учётом:

- уровня пользователя;
- предыдущих изученных слов;
- истории повторений;
- сложности;
- частотности;
- интересов пользователя в будущем;
- уже известных и исключённых слов.

Слово не должно снова становиться Daily Word, если пользователь уже достаточно хорошо его освоил или явно отметил как известное.

Для каждого Daily Word необходимо сохранять дату назначения.

Например:

```text
2026-10-08
Word: accomplish
Status: learning
```

Это позволяет гарантировать стабильность Daily Word в течение дня.

## 6. Система запоминания

Приложение использует интервальное повторение.

Для каждого слова необходимо хранить состояние памяти.

Пример состояний:

```text
new
learning
reviewing
remembered
known
suspended
```

Также необходимо хранить:

```text
repetitionCount
correctCount
incorrectCount
lastReviewedAt
nextReviewAt
interval
difficulty
stability
status
```

Правила статусов:

- `remembered` ставится **автоматически**, когда интервал слова достиг порога надёжного запоминания (см. раздел 35);
- `known` ставится **вручную** кнопкой «Я это знаю». Повторения для такого слова больше не планируются;
- `suspended` ставится вручную. Слово временно выпадает из выдачи и повторений.

Алгоритм повторений должен быть изолирован от остального приложения, чтобы его можно было заменить или улучшить без переписывания интерфейса и модели данных.

В качестве концепции можно использовать подход, похожий на Anki/FSRS, но реализация должна быть собственной и заменяемой.

## 7. Review

Во время повторения пользователь видит карточку слова.

На лицевой стороне:

```text
accomplish
```

После нажатия пользователь получает:

```text
translation
definition
pronunciation
example
```

Пользователь оценивает, насколько хорошо он вспомнил слово:

```text
Again
Hard
Good
Easy
```

После этого приложение рассчитывает следующий интервал.

Цель — минимизировать ручное управление расписанием.

В MVP повторение — **только флэшкарты** с оценкой Again/Hard/Good/Easy. Ввод слова по переводу и тесты с выбором ответа — после MVP.

Приложение должно быть прежде всего локальным.

- просматривать слова;

## 13. Встроенный словарь

Приложение должно иметь собственный локальный набор слов.

На старте желательно использовать примерно:

```text
1000–3000 words
```

Основной словарь должен быть ориентирован на:

- A2;
- B1;
- B2;
- IELTS;
- частотную лексику;
- phrasal verbs;
- collocations;
- полезные академические слова.

Данные должны храниться отдельно от Swift-кода, например в JSON.

Пример:

```json
{
  "word": "accomplish",
  "translation": "достигать, выполнять",
  "partOfSpeech": "verb",
  "level": "B1",
  "definition": "to successfully complete something",
  "examples": [
    "She accomplished her goal."
  ]
}
```

Источник встроенного словаря: **Wiktionary и другие открытые базы** с совместимой лицензией (например, CC BY-SA). Перед включением любого источника проверяется, что лицензия допускает распространение в приложении.

Для встроенных данных необходимо хранить информацию об источнике и лицензии у каждой записи (поля `source`, `license`). Эти сведения и требуемая атрибуция показываются на экране лицензий в Settings.

Нельзя без соответствующей лицензии распространять защищённые базы данных Oxford, Cambridge, Google и других коммерческих словарей.

## 16. Streak

Приложение может использовать простую систему серий.

День считается выполненным, если пользователь завершил хотя бы одну полноценную учебную активность.

Например:

```text
MON  TUE  WED  THU  FRI
 ✓    ✓    ✓    ✓    ✓
```

Главная цель streak — поддерживать регулярность, а не заставлять пользователя заниматься часами.

## 18. Авторизация и синхронизация

Приложение должно поддерживать режим без регистрации.

Пользователь может начать обучение сразу после установки.

Отдельная авторизация и собственный backend не планируются. Для восстановления данных и работы на нескольких устройствах используется **iCloud (CloudKit)** через SwiftData: пользователь входит в систему через свой Apple ID на устройстве.

В будущем архитектура должна поддерживать:

```text
iPhone
   ↓
Local SwiftData
   ↓
CloudKit (iCloud)
   ↑
Local SwiftData
   ↑
iPad / Mac
```

Синхронизация включается пользователем в Settings. Без iCloud приложение работает полностью локально.

Локальные данные не должны зависеть от наличия аккаунта.

## 30. Главный продуктовый принцип

Приложение не должно заставлять пользователя постоянно управлять обучением.

Пользователь должен открывать приложение и сразу понимать:

```text
WHAT SHOULD I LEARN?
WHAT SHOULD I REVIEW?
WHAT HAVE I MASTERED?
```

Приложение должно самостоятельно отвечать на эти вопросы.

Главная ценность — автоматическое превращение большого количества слов в управляемый процесс долгосрочного запоминания.

## 32. Что приложение НЕ должно делать

Не превращать приложение в:

- обычный онлайн-словарь;
- перегруженный образовательный портал;

## 35. Алгоритм SRS

Алгоритм — упрощённый SM-2 с элементами FSRS. Он реализован за протоколом `SpacedRepetitionEngine` и заменяется без изменений UI и модели данных.

Вход: текущий `LearningProgress`, оценка (`Again`, `Hard`, `Good`, `Easy`), текущая дата.
Выход: обновлённый `LearningProgress` (`status`, `interval`, `difficulty`, `stability`, `nextReviewAt`, счётчики).

Начальные значения нового слова:

```text
difficulty = 2.5
interval   = 0 дней
stability  = 0
status     = new
```

Влияние оценок (стартовые значения, подбираются тестами и практикой):

```text
Again → interval = 10 минут, difficulty −0.2, incorrectCount +1, status = learning
Hard  → interval × 1.2,      difficulty −0.15, correctCount +1
Good  → interval × difficulty, correctCount +1
Easy  → interval × difficulty × 1.3, difficulty +0.15, correctCount +1
```

Первые шаги нового слова: Good → 1 день, затем 3 дня, затем интервал × difficulty. Easy на первом показе → 4 дня.
Значение `difficulty` ограничено диапазоном 1.3–3.0.

Переходы статусов:

```text
new        → learning    при первом показе
learning   → reviewing   после первой оценки Good/Easy
reviewing  → learning    при Again (слово возвращается на короткие шаги)
reviewing  → remembered  когда interval ≥ 21 день
remembered → reviewing   при Again или Hard
any        → known       вручную («Я это знаю»)
any        → suspended   вручную; возврат в прежний статус
```

Просроченные повторения: слова с `nextReviewAt` в прошлом показываются в порядке «самые просроченные первыми». Интервал считается от фактической даты повторения. Дневной лимит повторений не вводится в MVP.

Тесты (раздел 27): все переходы статусов, границы `difficulty`, поведение при просрочке, детерминированность при фиксированной дате.

## 37. Онбординг и пустые состояния

### Первый запуск

```text
Welcome
  ↓
Language: English → Русский (в MVP одна пара, выбор фиксирован)
  ↓
Level: A2 / B1 / B2 / IELTS
  ↓
New words per day: 3 / 5 / 10 / 20
  ↓
Notifications (по желанию, можно пропустить)
  ↓
Today
```

Регистрация не требуется. Любой шаг можно изменить позже в Settings.

### Пустые состояния

```text
Нет слов на повторение
  → «На сегодня всё. Следующее повторение — завтра в 09:00.»
  → кнопка [ Learn new words ], если лимит новых слов не исчерпан.

Дневной лимит новых слов исчерпан
  → «Новые слова на сегодня закончились.»
  → кнопка добавить ещё слов вручную (по желанию).

Встроенный словарь исчерпан
  → «Вы прошли все слова для вашего уровня.»
  → предложение сменить уровень или добавить свои слова.

Words пуст / поиск без результатов
  → «Ничего не найдено» + кнопка [ + Add Word ] с введённым запросом.

Нет интернета при добавлении слова
  → слово сохраняется; пользователь видит «Данные можно дополнить позже».
```

### Пропущенные дни

Пропуск дня обнуляет текущий streak, но не штрафует интервалы повторений. Накопившиеся повторения показываются без чувства вины: «12 слов ждут повторения», без красных предупреждений.
