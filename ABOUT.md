# Vocabulary Learning App — ABOUT

## 1. О приложении

Это нативное приложение только для iPhone на iOS 27 и новее. iPad и Mac не поддерживаются: интерфейс, жесты и анимации проектируются под iPhone.

Приложение предназначено для долгосрочного изучения и запоминания иностранных слов и идиом.

Главная идея приложения — не быть обычным словарём, а стать персональной системой запоминания слов. Пользователь постепенно расширяет словарный запас, а приложение само определяет, какие слова показать сегодня, какие нужно повторить и какие уже хорошо запомнены.

Основной цикл обучения:

**NEW WORD → LEARN → REVIEW → REMEMBER → MASTER**

Соответствие этапов цикла статусам слова (см. раздел 6):

```text
NEW WORD → new
LEARN    → learning
REVIEW   → reviewing
REMEMBER → remembered   (автоматически, по интервалу)
MASTER   → known        (вручную, «Я это знаю»)
```

### Языки в MVP

В первой версии поддерживается одна пара языков: **английский → русский**. Интерфейс: английский и русский.

Модель данных сразу хранит изучаемый язык и язык перевода, чтобы позже добавить другие пары без миграции. Дополнительные языки в MVP не реализуются.

Приложение должно быть простым в использовании, быстрым, минималистичным и максимально нативным для экосистемы Apple.

---

## 2. Главная цель

Создать приложение, которое помогает пользователю регулярно и без перегрузки увеличивать словарный запас иностранного языка.

Приложение должно:

- каждый день предлагать новые полезные слова;
- автоматически планировать повторения;
- учитывать индивидуальный прогресс пользователя;
- помогать понять значение, произношение и использование слова;
- позволять добавлять собственные слова;
- работать без интернета для основной части обучения;
- постепенно синхронизировать данные между устройствами;
- превращать изучение слов в простую ежедневную привычку.

Главный принцип:

> Пользователь не должен думать о том, какие слова и когда ему повторять. Этим занимается приложение.

## 4. Основная концепция

Приложение объединяет четыре основных компонента:

1. **Dictionary**
   - перевод;
   - определения;
   - часть речи;
   - произношение;
   - IPA;
   - примеры;
   - синонимы;
   - антонимы;
   - аудио.

2. **Daily Words**
   - новые слова каждый день;
   - подбор слов на основе уровня и прогресса;
   - отсутствие повторной выдачи уже освоенных слов;
   - контроль дневного количества новых слов.

3. **Spaced Repetition**
   - автоматическое планирование повторений;
   - индивидуальные интервалы;
   - оценка сложности слова;
   - отслеживание правильных и неправильных ответов;
   - определение момента, когда слово можно считать хорошо запомненным.

4. **Personal Vocabulary**
   - пользовательские слова;
   - собственные примеры;
   - пользовательские заметки;
   - поиск;
   - статусы изучения;
   - история повторений.

## 5. Daily Word

Каждый день пользователь получает одно главное слово — **Daily Word**. Оно показывается на экране Today.

Остальные новые слова, до дневного лимита из Settings («количество новых слов в день»), попадают в очередь Learn. Daily Word всегда входит в этот лимит и считается первым из новых слов дня.

### Идиома дня

Кроме слова дня, Today показывает **идиому дня** — идиому из словаря, которую пользователь ещё учит. Карточка дня переключается между вкладками «Word» и «Idiom».

- идиома выбирается по дате детерминированно, как Daily Word; отмеченные «знаю» и отложенные идиомы пропускаются, пока есть другие;
- настройка «Idiom of the day» в Settings отключает идиомы полностью.


Приложение должно выбирать слово с учётом:

- уровня пользователя;
- предыдущих изученных слов;
- истории повторений;
- сложности;
- частотности;
- интересов пользователя в будущем;
- уже известных и исключённых слов.

Слово не должно снова становиться Daily Word, если пользователь уже достаточно хорошо его освоил или явно отметил как известное.

Для каждого Daily Word необходимо сохранять дату назначения.

Например:

```text
2026-10-08
Word: accomplish
Status: learning
```

Это позволяет гарантировать стабильность Daily Word в течение дня.

## 6. Система запоминания

Приложение использует интервальное повторение.

Для каждого слова необходимо хранить состояние памяти.

Пример состояний:

```text
new
learning
reviewing
remembered
known
suspended
```

Также необходимо хранить:

```text
repetitionCount
correctCount
incorrectCount
lastReviewedAt
nextReviewAt
interval
difficulty
stability
status
```

Правила статусов:

- `remembered` ставится **автоматически**, когда интервал слова достиг порога надёжного запоминания (см. раздел 35);
- `known` ставится **вручную** кнопкой «Я это знаю». Повторения для такого слова больше не планируются;
- `suspended` ставится вручную. Слово временно выпадает из выдачи и повторений.

Алгоритм повторений должен быть изолирован от остального приложения, чтобы его можно было заменить или улучшить без переписывания интерфейса и модели данных.

В качестве концепции можно использовать подход, похожий на Anki/FSRS, но реализация должна быть собственной и заменяемой.

## 7. Review

Во время повторения пользователь видит карточку слова.

На лицевой стороне:

```text
accomplish
```

После нажатия пользователь получает:

```text
translation
definition
pronunciation
example
```

Пользователь оценивает, насколько хорошо он вспомнил слово:

```text
Again
Hard
Good
Easy
```

После этого приложение рассчитывает следующий интервал.

Цель — минимизировать ручное управление расписанием.

В MVP повторение — **только флэшкарты** с оценкой Again/Hard/Good/Easy. Ввод слова по переводу и тесты с выбором ответа — после MVP.

## 9.1. Слова и идиомы

Идиома — это слово с частью речи `idiom`. Прогресс, статусы, повторения, примеры и заметка у неё такие же, как у слова.

Статусы (одинаковые для слов и идиом):

- **Learning** — учу: идиома в очереди Learn каждый день, интервал 1 день;
- **Reviewing** — просмотрел: повторение через несколько дней (интервал растёт);
- **Remembered** — запомнено: повторение через недели;
- **Known** — знаю: из повторений выходит, в упражнениях практически не появляется.

Карточка идиомы совпадает с карточкой слова: значение (с переводом по частям речи), примеры (из словаря и свои, сколько угодно), заметка, статус и следующее повторение, правка и удаление.

**Встроенные идиомы.** В словаре 114 распространённых английских идиом (см. `Tools/idioms`). Определения и примеры — из английского Викисловаря через kaikki.org (CC BY-SA), русские значения — из русского Викисловаря или переводов английского, плохие переводы исправлены вручную (`overrides.json`). Встроенные идиомы попадают в очередь новых слов вместе со словами (после частотных), их можно учить по дневному лимиту.

**Свои идиомы.** Добавляются в форме «Idiom»: текст, значение пишет пользователь или берёт из Викисловаря при печати (kaikki.org, без ключа); пример необязателен. Одна и та же идиома дважды не сохраняется. Свои записи удаляются вместе с примерами и прогрессом; встроенные — нет.

**Перенос.** Прежняя таблица личных идиом переносится в слова один раз при запуске (`PhraseMigration`): текст, значение, заметка, примеры и статус «знаю» сохраняются.

Разделы Words и Idioms — один список: вкладки переключают вид, поиск и статусы работают в каждом разделе отдельно. Слово дня никогда не бывает идиомой.

API keys и секреты никогда не должны находиться непосредственно в клиентском приложении.

## 13. Встроенный словарь

Приложение должно иметь собственный локальный набор слов.

На старте желательно использовать примерно:

```text
1000–3000 words
```

Уровни встроенного словаря — по шкале CEFR, от A1 до C1:

- A1 — первые повседневные слова;
- A2 — повседневные слова и фразы;
- B1 — работа, поездки, мнения;
- B2 — абстрактные темы, оттенки значения;
- C1 — тонкие смысловые различия, академические тексты.

Уровень из онбординга задаёт, какие слова попадают в Daily Word и очередь новых слов. Отдельный уровень IELTS убран: экзаменационная лексика входит в C1 и B2.

Источники для уровней A1–C1 — открытые списки CEFR:

- **CEFR-J Vocabulary Profile** (A1–B2): бесплатно для исследований и коммерческого использования при условии ссылки на источник (Tono Laboratory, Tokyo University of Foreign Studies);
- **Octanove C1/C2 Vocabulary Profile** (C1): лицензия CC BY-SA 4.0, производные работы распространяются под той же лицензией.

Атрибуция обоих источников показывается на экране «Sources & licenses» в Settings. Перед загрузкой списков проверяются актуальные версии и условия на сайтах источников.

Дополнительно в словарь входят частотная лексика, phrasal verbs и collocations по мере готовности данных.

Данные должны храниться отдельно от Swift-кода, например в JSON.

Пример:

```json
{
  "word": "accomplish",
  "translation": "достигать, выполнять",
  "partOfSpeech": "verb",
  "level": "B1",
  "definition": "to successfully complete something",
  "examples": [
    "She accomplished her goal."
  ]
}
```

Источник встроенного словаря: **Wiktionary и другие открытые базы** с совместимой лицензией (например, CC BY-SA). Перед включением любого источника проверяется, что лицензия допускает распространение в приложении.

### Значения по частям речи

У многих слов несколько частей речи с разными переводами: `book` — «книга» и «бронировать», `fine` — «хороший» и «штрафовать». Слово хранит список значений `meanings: [{partOfSpeech, translation}]`; первое значение — основное, оно же показывается в списке слов и ищется в первую очередь. Карточки Today, Learn и экран слова показывают все значения с короткой меткой `n`, `v`, `adj`, `adv`.

Как собирается перевод (`Tools/build_seed.py`):

- русский Викисловарь (kaikki.org/ruwiktionary) — основной источник для слов, чьи статьи загружены при сборке (`--fetch-ru`): толкования уже на русском и разбиты по частям речи;
- таблицы переводов английского Викисловаря — для остальных слов и недостающих частей речи. Значения внутри части речи упорядочены по числу переводов на все языки (чем шире переведено значение, тем оно употребительнее), узкие значения (юридические, спортивные, морские и т. п.) пропускаются;
- у глагола берётся инфинитив несовершенного вида, без пары совершенного («оставлять», а не «оставлять, оставить»); у других частей речи глагольные формы отсекаются;
- вес русского слова — сумма весов значений, где оно встречается: «интерес» покрывает три значения interest и идёт раньше финансового «процент»; значения слабее 10 % главного (например, «чайка» у beard) отбрасываются;
- предлоги — отдельная часть речи: about — «о, про», а не только наречие «примерно»;
- служебные слова (местоимения, кванторы all/each/any, союзы) в словарь не входят.

**Правка значений.** На экране правки слова у каждой части речи своё поле; лишнее значение убирается кнопкой ×. Правка сразу видна в начатой сессии Learn: слова очереди перечитываются из базы при возврате на вкладку и при открытии сессии.

Встроенный словарь версионируется (`seedVersion` в `seed-manifest.json`). При новой версии приложение один раз обновляет встроенные слова: меняет переводы и значения у слов, которые пользователь не правил, добавляет новые и удаляет выбывшие, если их ещё не начинали учить. Прогресс и правки пользователя не трогаются.

Для встроенных данных необходимо хранить информацию об источнике и лицензии у каждой записи (поля `source`, `license`). Эти сведения и требуемая атрибуция показываются на экране лицензий в Settings.

Нельзя без соответствующей лицензии распространять защищённые базы данных Oxford, Cambridge, Google и других коммерческих словарей.

## 14. Поиск

Поиск должен работать быстро и локально.

Результаты сортируются по совпадению, сначала самые точные:

1. точное совпадение лемы (`achieve` → `achieve`);
2. начинается с запроса (`achieve` → `achievement`);
3. содержит запрос в другой части текста (переводе, определении, заметке, примере).

Поиск по базе запускается с паузой около 150 мс после последнего символа. Регистр и лишние пробелы не влияют на результат.

Искать необходимо по:

- оригинальному слову;
- переводу;
- определению;
- пользовательскому примеру;
- пользовательской заметке.

Пример:

```text
Search: achieve
```

Результаты могут содержать:

```text
achieve
achievement
achievable
```

Поиск должен работать без сетевого запроса.

### Learn

Экран обучения: два режима переключателем вверху — **Cards** (карточки SRS) и **Practice** (упражнения).

**Cards.** Колода на сегодня: передняя карточка со счётчиком, составом (зелёные точки — новые слова, кольца — повторения) и временем; план сессии под ней. Сессия открывается на весь экран «зумом» из карточки.

**Practice.** Упражнения по словам, которые пользователь учит, из той же базы:

- `meaning` — дано слово, выбрать значение по-русски;
- `reverse` — дано значение, выбрать слово;
- `context` — дано предложение с пропуском (из примеров), выбрать слово или идиому; если примера нет, такой вопрос не задаётся.

Четыре варианта: правильный и три отвлекающих того же вида (слово или идиома) и части речи, если таких хватает. Основные вопросы — из статусов Learning и Reviewing; Remembered добавляются, если основных не хватает; Known попадает не больше одного раза за сессию. Сессия — до 12 вопросов. Правильный ответ подсвечивается сразу, в конце — итог.

Упражнения SRS не меняют: интервалы и статусы меняются только в Cards. Так упражнения не сбивают расписание; при желании их можно засчитывать как повторения (одна строка в `PracticeUseCase`).

## 18. Авторизация и синхронизация

Приложение работает без аккаунта: пользователь может начать обучение сразу после установки. Все данные хранятся локально в SwiftData, и без входа приложение полностью работоспособно.

Вход через Google — необязательный. Он нужен для:

- восстановления словаря, прогресса и истории повторений на новом устройстве;
- синхронизации между устройствами пользователя на iOS;
- резервной копии настроек.

Поддерживаемые способы входа:

```text
Continue with Google        основной способ (OAuth 2.0 с PKCE)
Sign in with Apple          обязательная альтернатива по правилам App Store
Continue without account    работа только локально
```

Правила:

- выход из аккаунта не удаляет локальные данные;
- удаление аккаунта удаляет синхронизированные данные на сервере, локальная копия остаётся, если пользователь не выбрал иное;
- токены хранятся в Keychain, никогда в UserDefaults;
- на клиенте нет секретных ключей: только публичный client ID и PKCE;
- вход не обязателен ни для одной функции обучения, включая Daily Word, повторения и словарь.

Схема хранения синхронизированных данных (сервер и провайдер) выбирается отдельно и фиксируется отдельным решением. Вход через Google не означает iCloud: Google-аккаунт не даёт доступа к CloudKit, поэтому CloudKit в этой схеме не используется.

В будущем архитектура должна поддерживать:

```text
iPhone
   ↓
Local SwiftData
   ↓
SyncService (отдельный адаптер)
   ↓
Backend API ← токен Google (после проверки на сервере)
```

Локальные данные не должны зависеть от наличия аккаунта.

## 35. Алгоритм SRS

Алгоритм — упрощённый SM-2 с элементами FSRS. Он реализован за протоколом `SpacedRepetitionEngine` и заменяется без изменений UI и модели данных.

Вход: текущий `LearningProgress`, оценка (`Again`, `Hard`, `Good`, `Easy`), текущая дата.
Выход: обновлённый `LearningProgress` (`status`, `interval`, `difficulty`, `stability`, `nextReviewAt`, счётчики).

Начальные значения нового слова:

```text
difficulty = 2.5
interval   = 0 дней
stability  = 0
status     = new
```

Влияние оценок (стартовые значения, подбираются тестами и практикой):

```text
Again → interval = 10 минут, difficulty −0.2, incorrectCount +1, status = learning
Hard  → interval × 1.2,      difficulty −0.15, correctCount +1
Good  → interval × difficulty, correctCount +1
Easy  → interval × difficulty × 1.3, difficulty +0.15, correctCount +1
```

Первые шаги нового слова: Good → 1 день, затем 3 дня, затем интервал × difficulty. Easy на первом показе → 4 дня.
Значение `difficulty` ограничено диапазоном 1.3–3.0.

Переходы статусов:

```text
new        → learning    при первом показе
learning   → reviewing   после первой оценки Good/Easy
reviewing  → learning    при Again (слово возвращается на короткие шаги)
reviewing  → remembered  когда interval ≥ 21 день
remembered → reviewing   при Again или Hard
any        → known       вручную («Я это знаю»)
any        → suspended   вручную; возврат в прежний статус
```

Просроченные повторения: слова с `nextReviewAt` в прошлом показываются в порядке «самые просроченные первыми». Интервал считается от фактической даты повторения. Дневной лимит повторений не вводится в MVP.

Тесты (раздел 27): все переходы статусов, границы `difficulty`, поведение при просрочке, детерминированность при фиксированной дате.

### Пустые состояния

```text
Нет слов на повторение
  → «На сегодня всё. Следующее повторение — завтра в 09:00.»
  → кнопка [ Learn new words ], если лимит новых слов не исчерпан.

Дневной лимит новых слов исчерпан
  → «Новые слова на сегодня закончились.»
  → кнопка добавить ещё слов вручную (по желанию).

Встроенный словарь исчерпан
  → «Вы прошли все слова для вашего уровня.»
  → предложение сменить уровень или добавить свои слова.

Words пуст / поиск без результатов
  → «Ничего не найдено» + кнопка [ + Add Word ] с введённым запросом.

Нет интернета при добавлении слова
  → слово сохраняется; пользователь видит «Данные можно дополнить позже».
```

### Пропущенные дни

Пропуск дня обнуляет текущий streak, но не штрафует интервалы повторений. Накопившиеся повторения показываются без чувства вины: «12 слов ждут повторения», без красных предупреждений.
